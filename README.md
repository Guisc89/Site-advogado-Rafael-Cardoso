# Site Rafael Cardoso Advocacia

Este site foi desenvolvido para o Rafael, um cliente e amigo muito especial.

A ideia foi criar um layout funcional para apresentar a proposta do site de forma mais clara. Assim, ele pode visualizar o resultado, pedir os ajustes que achar necessários e aprovar tudo antes de colocarmos o projeto no ar.

O site foi feito com HTML, CSS e JavaScript e conta com uma estrutura responsiva, apresentação dos serviços, informações profissionais e acesso direto ao WhatsApp.

## Como visualizar

Não é necessário instalar dependências. Basta abrir o arquivo `index.html` no navegador.

## Status

O projeto está em fase de ajustes e aprovação.
